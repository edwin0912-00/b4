# Security policy

B4 is an early developer alpha. The current supported release is `v0.7.0-alpha.1` on Apple Silicon macOS 26.0 or newer.

Report exploitable vulnerabilities through [GitHub private vulnerability reporting](https://github.com/edwin0912-00/b4/security/advisories/new), under **Security → Report a vulnerability**. If the private channel is unavailable, open a public issue asking for a private reporting route without including exploit details, credentials, private project files, or personal data.

For a report, include the affected alpha version, macOS version and architecture, a concise impact description, and a minimal synthetic reproduction when safe. Do not attach customer footage or private projects. Maintainers will acknowledge and investigate reports as capacity allows; no response-time guarantee is made.
