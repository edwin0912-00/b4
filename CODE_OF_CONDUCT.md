# Community conduct

We want B4 discussions and contributions to be useful, respectful, and welcoming. Treat people with respect regardless of their background or experience. Critique ideas and code directly without personal attacks. Harassment, discrimination, threats, doxxing, and sharing private information without consent are not acceptable.

Project maintainers may remove harmful content, request changes, pause a discussion, or restrict participation when needed to protect the community. For conduct concerns, contact a project maintainer through GitHub; avoid posting another person's private information in a public issue. Report security vulnerabilities using the process in [SECURITY.md](SECURITY.md), not a public issue.
